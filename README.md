# 找貓

手機遊戲「找貓」（Queens / Star Battle 類型）的網頁版與解題器。

## 網頁遊戲

直接用瀏覽器打開 `index.html` 就能玩，不需要伺服器。
關卡由內建產生器即時產生，並保證唯一解；同一關每次打開都是同一題。

- 點一下格子：標叉 / 取消叉；連點兩下：放貓；手指滑過一排格子：整排標叉（從叉開始滑則整排清除）
- 放對的貓會鎖定，不能再移除；放錯的格子顯示紅色錯誤並鎖定
- 上方五隻貓是命數，錯 5 次即失敗，可按「重來」；找齊所有貓即過關
- 計時、上一關 / 下一關、跳到任一關；進度與最佳時間存在瀏覽器
- 設定裡可開關「自動標叉」
- 難度分級：第 1 到 10 關簡單（6×6、7×7）、11 到 30 關中等（8×8、9×9）、31 關起困難（10×10）

想放到網路上，可在 GitHub 的 Settings → Pages 選擇 main 分支根目錄，
就會得到一個可用手機打開的網址。

### 產生器原理

1. 隨機擺出一組合法的貓位置（每行每列一隻、互不相鄰）
2. 以每隻貓為種子，用加權隨機洪水填充長出顏色區域
3. 用解題器檢查；若有第二組解，把那組解多出來的貓所在格改成鄰近顏色，
   讓它失效但原答案不受影響，重複到唯一解為止
4. 用「模擬人類推理」的解題器評定難度，不符合該關要求的題目就丟掉重來

### 難度判定

模擬玩家只用固定技巧一步步推理，看需要用到哪一層技巧才能推完：

| 等級 | 需要的技巧 |
|---|---|
| 簡單 | 某行、列或區域只剩一格可放；某區域的候選格全在同一行或列，鎖住該行列 |
| 中等 | 放某格會讓另一個區域沒有位置，排除該格；k 個區域剛好佔 k 行或列，其他區域讓開 |
| 困難 | 假設放某格，用簡單技巧推下去會矛盾，排除該格 |

只靠簡單技巧推完的是簡單題；需要中等技巧的是中等題；需要假設推演的是困難題。
純邏輯推不完、必須猜的題目不採用。

## 解題器

## 規則

1. 每種顏色區域恰好一隻貓
2. 每行、每列恰好一隻貓
3. 貓咪不能相鄰（包含斜角的八個方向）

## 使用方式

需要 Python 3，沒有其他相依套件。

```bash
python3 cat_solver.py puzzles/level25.txt
```

輸出：

## 盤面格式

純文字檔，每行一列，每格一個字元代表顏色，`#` 開頭的行是註解。
盤面必須是正方形，顏色種類數要等於邊長。範例見 `puzzles/level25.txt`。

## 解法

回溯法（backtracking）：逐列嘗試放貓，只保留欄未用、顏色未用、
且不與上一列的貓相鄰的位置，走不通就退回。10×10 的盤面瞬間完成。
